# 하이씨앤씨 펜클래스

영어 수업에서 PDF 교재와 스마트펜 필기 기록을 관리하는 PC 프로그램입니다. 이 저장소에서 설치 파일과 외부 공개용 소스를 받을 수 있습니다.

## 프로그램 다운로드

**[Windows 설치 ZIP 받기](https://github.com/kj2286/hicnc-penclass-public/releases/download/v0.1.2/HICNC-Penclass_0.1.2_Windows.zip)** · [릴리스와 검증 안내](https://github.com/kj2286/hicnc-penclass-public/releases/tag/v0.1.2)

ZIP을 풀고 `HICNC-Penclass_0.1.2_Windows-x64-setup.exe`를 실행하세요. 설치 후 프로그램을 열어 **빠르게 시작하기**를 누르면 아이디와 비밀번호 없이 시작할 수 있습니다. 인터넷 연결이 필요합니다.

Windows 설치 파일은 서명되지 않았습니다. SmartScreen 경고가 나타날 수 있으니 다운로드 출처와 릴리스의 SHA-256을 확인하세요. ZIP에는 설치 안내와 실제 검증 범위를 함께 넣었습니다. 이번 공개 릴리스에는 Windows x64 설치본을 제공합니다.

## 수업에서 사용하는 흐름

1. **교재 만들기**에서 PDF를 올리고 ncode를 입힌 PDF를 다운로드합니다.
2. 출력한 교재를 학생이 스마트펜으로 풉니다.
3. 크래들을 PC에 연결해 필기 데이터를 받습니다.
4. 학생 기록에서 필기를 확인하고 문항별 분석과 리포트를 이용합니다.

위 목록은 프로그램의 사용 흐름입니다. 실물 펜·크래들·프린터와 필기 분석부터 리포트까지의 전체 흐름은 이번 Windows 검증에서 확인하지 않았습니다. 확인한 항목은 [검증 범위](docs/VALIDATION.md)에 구분했습니다.

빠르게 시작하기는 이 PC의 앱 프로필에 연결된 교실을 사용합니다. 앱 프로필을 삭제하면 기존 교실로 돌아오는 복구 기능은 현재 제공하지 않습니다.

## 소스 실행

Node.js 24를 설치한 뒤 저장소 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

환경변수를 설정하지 않으면 서버 연결 안내 화면이 열립니다. 실제 교재 처리와 저장 기능을 운영하려면 별도의 Supabase 및 NGS/FPS 서버 설정이 필요합니다. `npm run dev`만으로 전체 서버 기능이 실행되지는 않습니다.

```sh
npm run build
npm test
npm run test:desktop
```

자세한 준비 항목은 [개발 환경 안내](docs/SETUP.md)를 확인하세요.

## 공개 소스 범위

웹 화면, 서버 API, DB 스키마와 PC 앱 소스를 담았습니다. 비밀키·사용자 데이터·기존 Git 이력·내부 운영 문서는 포함하지 않습니다.

별도 비공개 펜 SDK와 실제 기기 캡처, 제공받은 평가자료·교재 원문은 제외했습니다. 그래서 **PC 앱을 소스에서 빌드하려면 별도 SDK가 필요합니다.** 공개 소스의 평가자료 검색 데이터는 비어 있으며, 자료가 없으면 원문을 참조하지 않는 기본 분석 경로를 사용합니다. 공개 설치 파일은 기존 검증본 그대로입니다.
