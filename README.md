# 하이씨앤씨 펜클래스

PDF 교재와 스마트펜 필기 기록을 관리하는 PC 프로그램의 외부 개발 작업용 소스입니다. 이 저장소를 내려받아 GPT·Codex와 함께 수정할 수 있습니다.

## 소스 받기

GitHub의 **Code → Download ZIP**으로 소스를 받거나 아래 명령으로 복제하세요.

```sh
git clone https://github.com/kj2286/hicnc-penclass-public.git
cd hicnc-penclass-public
npm ci
npm run dev
```

Node.js 24가 필요합니다. 서버 설정을 비우면 연결 안내 화면이 열립니다. 화면 빌드와 단위 검사는 비밀키 없이 실행할 수 있습니다.

```sh
npm run build
npm test
npm run test:desktop
```

실제 PDF 처리·저장에는 별도의 서버 설정이 필요합니다. [개발 환경 안내](docs/SETUP.md)와 [외부 작업자 인계](docs/DEVELOPER-HANDOFF.md)를 먼저 읽어 주세요.

## 현재 학생 관리 방식

학생 추가는 이름·학년·연락처 등의 기록만 등록합니다. 학생 로그인 계정이나 아이디·비밀번호를 발급하지 않습니다. 목록과 상세 화면의 아이디·비밀번호 표시, 복사와 재발급 기능도 제거했습니다.

필기와 펜 배정에는 화면에 표시하지 않는 내부 식별자를 사용합니다. 기존 학생의 식별자와 필기 기록은 유지합니다. 이 변경을 기존 서버에 적용할 때는 `supabase/029_student_records_without_auth.sql`을 먼저 검토·적용해야 합니다. 이번 작업에서는 운영 DB 변경이나 서버 재배포를 하지 않았습니다.

## GPT·Codex에 전달할 문장

> README.md, HANDOFF.md, docs/DEVELOPER-HANDOFF.md를 먼저 읽고 작업해 주세요. 학생은 로그인 계정 없이 기록만 관리합니다. 학생 아이디·비밀번호 발급 기능을 다시 넣지 마세요. 기존 필기 기록과 교사 인증을 유지하고, 수정 후 빌드와 테스트 결과를 알려 주세요. 운영 DB 변경이나 배포는 실행할 내용을 설명하고 승인을 받은 뒤 진행해 주세요.

## 포함 범위와 제약

웹 화면, 서버 API, DB 스키마와 PC 앱 소스를 담았습니다. 비밀키·사용자 데이터·내부 운영 문서·별도 비공개 펜 SDK·평가자료 원문은 제외했습니다. 원문 검색 데이터는 빈 값이며 기본 분석 경로를 사용합니다.

PC 앱을 소스에서 빌드하려면 별도 펜 SDK가 필요합니다. 이번 전달물은 개발용 소스이며 설치 프로그램 ZIP은 새로 만들지 않습니다. 기존 릴리스의 설치 파일은 이번 학생 관리 변경을 포함한 새 빌드가 아닙니다.

기존 검증 범위는 [검증 기록](docs/VALIDATION.md), 의존성 라이선스는 [외부 구성 요소 고지](THIRD_PARTY_NOTICES.md)에 정리했습니다.
