# 검증 범위

## 학생 계정 제거 변경

2026-09-29에 학생 등록을 계정 없는 기록 등록으로 바꿨습니다. 공개 소스의 `npm run build`, `npm test`, `npm run test:desktop`을 통과했습니다.

- 학생 API 10개 검사: Auth 미생성, 입력·권한 확인, 등록 실패 처리, 재발급 종료, 기존 ID를 유지하는 수정·퇴원·복귀, 신규·기존 학생 기록 삭제 시 Auth 보존.
- 접근 제한 6개 검사: 기존 학생 JWT 거부와 교사·관리자 인증 유지.
- 실제 학생관리 컴포넌트의 가상 UI 8개 검사: 등록·상세 수정·계속 등록·실패 입력 보존·필기 화면 이동. 외부·운영 API 요청과 브라우저 오류는 0건이었습니다.

서버 검사는 가상 응답을 사용했습니다. 029 SQL은 정적 검사·코드 검토만 마쳤으며 실제 DB 적용·RLS 실행 검증과 운영 배포는 하지 않았습니다. 아래 Windows 설치본 검증은 이번 소스 변경 전의 기록입니다.

## Windows 설치본 0.1.2

2026-09-20에 Windows Server 2022 가상 머신과 WebView2 131.0.2903.86에서 실제 설치본을 확인했습니다. 최초 실행 11단계, 재실행 7단계, 같은 버전 재설치 후 7단계로 총 25단계를 통과했습니다.

확인한 기능은 빠르게 시작하기, 폴더 생성·이름 변경, 2페이지 영어 PDF 업로드와 ncode PDF 다운로드, 네이티브 PDF 저장, 재실행·재설치 후 기록 유지입니다. 앱 설치와 제거도 확인했습니다. 다운로드 PDF는 두 페이지를 렌더링해 영어 내용과 ncode 점을 확인했습니다.

| 항목 | 결과 |
| --- | --- |
| Server 2022에서 위 기능 25단계 | 통과 |
| Windows 10/11 실물 PC | 미검증 |
| 일반 사용자 권한에서의 앱 동작 | 미검증 |
| Server 2025 환경 | 검증 완료하지 못함 |
| 실제 스마트펜·크래들·프린터 | 미검증 |
| 필기 분석 → 문항별 분석 → 리포트 전체 흐름 | 미검증 |
| Windows 파일 선택 창 조작·드래그 앤 드롭 | 미검증 |

테스트에서는 업로드 입력에 PDF 파일을 직접 지정했습니다. PDF 저장 명령의 확인 결과가 리포트 화면 전체의 검증을 뜻하지는 않습니다.

EXE는 Windows x64용이며 Authenticode 서명이 없습니다. 버전은 0.1.2입니다.

```text
6384f7ea5cc30cc91d594c6b41e87260374bef9944a5d3a2a7e0c65944ad84c5  HICNC-Penclass_0.1.2_Windows-x64-setup.exe
```

이번 전달물은 수정한 소스입니다. 새 설치 프로그램 ZIP은 만들지 않았습니다. SDK와 원문 자료를 제외한 범위 및 실행 조건은 [개발 환경 안내](SETUP.md)를 참고하세요.
